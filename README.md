## About

I'm a self-taught developer and a student, still very much in progress.

Backend and applied AI are where I'm pointing: systems that behave predictably, and models that learn from data.

I'm curious about physics and philosophy, and I try to learn the Feynman way: explain it plainly, then build it to check I understood.

Stoicism is my operating manual. Do the work that's in my control, then ship the next small thing.
